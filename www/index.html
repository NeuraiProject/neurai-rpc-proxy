How the RPC works

The proxy accepts an RPC method and its parameters, checks its allowlist, then calls the configured node. Reads that are safe to cache are retained only until the next block.

01

Choose a method

Pick a supported Neurai RPC method from the explorer below, such as getblockcount.

Send JSON

03

Use the result

The response is JSON in the form { "result": … }. Unsupported methods are rejected before they reach the node.

About the gateway port

The DePIN-Test node can also run its own direct TCP messaging gateway. That is a node feature, not an HTTP endpoint provided by this proxy.

  • The proxy never connects to or publishes that TCP gateway.
  • For the testnet branch, its default is port 19002.
  • Use it only for a client that explicitly implements its separate protocol.
